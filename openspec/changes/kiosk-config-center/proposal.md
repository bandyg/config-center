# Kiosk 配置管理中心

## Why

目前几十台 Kiosk 投注终端每台本地跑着 config-serv，管自己的配置。运维人员要改配置时，只能 SSH 到每台机器手动修改，效率极低且容易出错。CTC 系统只面向操作员，无法方便地查看、对比、批量修改各终端的配置。

需要一个**统一配置管理中心**，让运维人员在一台管理服务器上就能：

- 查看所有终端的配置
- 在线/离线状态一目了然
- 修改单台配置
- 批量修改多台或全部终端的配置
- 不同终端之间对比差异

## What Changes

在管理服务器 (bhs-4) 上新建一个 **Kiosk Config Center** 服务，通过 HTTP 代理各终端 config-serv 的 API，提供集中管理和 Web UI。

### 新增的设施

1. **FastAPI 后端** — 配置管理中心 API，负责终端发现、配置代理读写、批量操作
2. **Web UI** — 浏览器访问的管理界面
3. **终端注册/发现** — 静态配置文件或简单探测机制

### 受影响的现有组件

- **config-serv** — 无改动，复用其现有 REST API
- **log-serv** — 无改动，新增服务的日志可以复用它

### 不做的

- 不替换终端本地的 config-serv
- 不实现实时推送（终端不装 agent）
- 不实现用户权限管理（后续可加）

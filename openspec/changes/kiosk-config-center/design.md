# Kiosk 配置管理中心 — 架构设计

## 整体架构

```
┌──────────────────────────────────────────────────┐
│                  用户浏览器                        │
│         http://100.103.42.118:8300               │
└─────────────────────┬────────────────────────────┘
                      │
┌─────────────────────▼────────────────────────────┐
│         bhs-4 管理服务器 (100.66.5.26)             │
│                                                    │
│  ┌──────────────────────────────────────────────┐  │
│  │        FastAPI (端口 8300)                    │  │
│  │                                               │  │
│  │  GET  /api/terminals          ← 终端列表      │  │
│  │  GET  /api/terminals/{ip}     ← 终端详情      │  │
│  │  GET  /api/proxy/{ip}/...     ← 代理读配置     │  │
│  │  PUT  /api/proxy/{ip}/...     ← 代理写配置     │  │
│  │  POST /api/batch              ← 批量写入       │  │
│  │                                               │  │
│  │  ┌──────────────────────────────────────┐     │  │
│  │  │ 静态终端配置表 (terminals.yaml)       │     │  │
│  │  │  - IP 清单 + 别名 + 分组              │     │  │
│  │  └──────────────────────────────────────┘     │  │
│  └───────────────────┬──────────────────────────┘  │
└──────────────────────┼─────────────────────────────┘
                       │ HTTP (通过 Tailscale/内网)
       ┌───────────────┼───────────────┐
       │               │               │
  T1 (:8081)      T2 (:8081)     T3 (:8081)   ... T50
```

## 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| **后端** | FastAPI (Python) | 轻量、异步、自动 OpenAPI 文档，跟巡学项目一致 |
| **前端** | HTML + HTMX + Jinja2 | 足够用，不需要 Angular 重量级框架，可快速迭代 |
| **HTTP 客户端** | httpx (async) | 异步代理请求到各终端 |
| **终端清单** | YAML 文件 | 简单可编辑，无需数据库 |
| **部署** | uvicorn systemd | 跟巡学项目一致，单端口运行 |

## 终端发现

使用静态 YAML 配置文件 `terminals.yaml`：

```yaml
terminals:
  - ip: 10.202.1.1
    alias: "分店A-01号机"
    group: "分店A"
    port: 8081
  - ip: 10.202.1.2
    alias: "分店A-02号机"
    group: "分店A"
    port: 8081
  - ip: 10.202.1.99
    alias: "测试机-20号窗"
    group: "测试组"
    port: 8081
```

运行时自动检测在线状态（ping config-serv 的根路径）。

## API 设计

### GET /api/terminals
返回终端列表，包含在线状态：
```json
[
  {"ip": "10.202.1.1", "alias": "分店A-01号机", "group": "分店A", "online": true, "configVersion": "61.0"},
  {"ip": "10.202.1.2", "alias": "分店A-02号机", "group": "分店A", "online": false}
]
```

### GET /api/proxy/{ip}/config
获取某终端全部配置（代理转发到 config-serv）

### GET /api/proxy/{ip}/config/{key}
获取某终端指定配置项

### PUT /api/proxy/{ip}/config/{key}
修改某终端指定配置项

### POST /api/batch
批量修改（指定终端列表或分组）
```json
{
  "targets": {"ips": ["10.202.1.1", "10.202.1.2"], "groups": ["分店A"]},
  "configs": {"serviceConfig": {"demoMode": false}}
}
```

### GET /api/compare
对比多台终端的配置差异

## 前端页面

| 页面 | 路由 | 功能 |
|------|------|------|
| 终端列表 | `/` | 所有终端状态一览，在线/离线指示灯 |
| 终端详情 | `/terminal/{ip}` | 查看该终端全部配置 |
| 配置编辑 | `/terminal/{ip}/edit` | 修改该终端配置 |
| 批量操作 | `/batch` | 选择终端 + 分组 → 批量修改 |
| 配置对比 | `/compare` | 选择多台 → 差异高亮 |

## 1. 这个工具是干什么的？

你有很多台 Kiosk 终端机器（收银机/自助机等），每台终端上跑着一个叫 `config-serv` 的小服务，负责管理这台终端的配置。

**Kiosk Config Center** 是一个网页工具，让你：

- 在浏览器里看到所有终端的**在线状态**（哪些开着、哪些关了）
- 查看和修改每台终端的**配置**（比如界面语言、超时时间、服务器地址等）
- **批量修改**多台终端的同一配置项
- **对比**不同终端的配置差异
- **回滚**到以前的配置版本

简单说：**不用登录每台机器，在浏览器里就能统一管理所有终端的设置。**不会编程也能用。

## 2. 你需要准备什么

### 硬件和网络

- 一台 Windows 电脑（称为「管理服务器」或 BC Server）
- 这台电脑与 Kiosk 终端在**同一个局域网**内
- 终端上的 `config-serv` 服务已经正常运行（默认端口 8081）

### 软件

- **方式一：EXE（推荐，最简单）**
  - 拿到 `KioskConfigCenter.exe` 文件，双击就能运行

- **方式二：Python 运行**
  - 电脑上已安装 Python 3.9 或更高版本
  - 有 `run.py` 和 `app/` 文件夹

## 3. 启动程序

### 方式一：双击 EXE（最简单）

1. 找到 `KioskConfigCenter.exe`
2. **双击**它
3. 会弹出一个黑色控制台窗口（不要关掉它！）
4. 稍等 1~2 秒，浏览器会自动打开一个页面
5. 如果浏览器没自动打开，手动打开浏览器，在地址栏输入：`http://127.0.0.1:8300`

> ⚠️ **黑色窗口就是程序本体**，关掉窗口程序就停了。
> 如果想在后台运行，Windows 搜索 → 输入「任务计划程序」→ 创建开机启动任务。

### 方式二：Python 运行

1. 打开**终端**（cmd 或 PowerShell）
2. 进入程序所在目录：
   ```
   cd d:\projects\kiosk-config-center
   ```
3. 运行：
   ```
   python run.py
   ```
4. 看到如下输出表示启动成功：
   ```
   🖥  Kiosk Config Center v1.0
   📡  http://127.0.0.1:8300/
   🔧 Mode: BC
   ```
5. 打开浏览器，访问 `http://127.0.0.1:8300`

### 如果端口被占用（常见问题）

如果你看到红色错误信息说「端口 8300 已被占用」，说明之前有一个没关干净：

1. 按 `Ctrl+Alt+Delete` 打开**任务管理器**
2. 找到 `KioskConfigCenter.exe` → 右键 → **结束任务**
3. 重新双击 EXE 即可

也可以换个端口启动：
```
set KIOSK_PORT=8301
python run.py
```
浏览器访问 `http://127.0.0.1:8301`


### 每个部分是什么意思

| 区域 | 说明 |
|------|------|
| **统计卡片**（顶部数字） | 总共有多少台终端、多少台在线、分了多少个组 |
| **搜索框** | 输入 IP 地址或别名，快速找到某台终端 |
| **分组下拉** | 筛选只看某个组的终端 |
| **➕ 添加终端** | 手动添加一台新的终端到列表 |
| **🔍 扫描子网** | 自动扫描局域网内所有开放的终端 |
| **表格** | 所有终端的列表，一行一台 |

### 表格列说明

| 列 | 意思 | 怎么看 |
|----|------|--------|
| **状态** | ✅ 在线 / ❌ 离线 | 绿色=正常运行，红色=无法连接 |
| **别名** | 终端的一个好记的名字 | 如果没设置别名，就显示 IP 地址 |
| **IP** | 终端在网络中的地址 | 类似于门牌号 |
| **分组** | 终端所属的组 | 比如「大堂」「入口」「自助区」 |
| **健康度** | 终端的状态评分（0~100） | 绿色≥80、黄色50~79、红色<50 |
| **配置版本** | 当前配置的版本号 | 空表示离线获取不到 |
| **操作** | 点击「查看」进入详情页 | 查看和修改配置都在这里 |

### 配置项面板

每个配置项（如 `terminalFunction`、`serviceConfig` 等）是一个可折叠的卡片：

- **点击标题栏**（灰色条）可以展开或收起
- 每个面板左上角是配置项的名字
- 右上角有 **保存**、**格式化**、**树形预览** 等按钮

### 两种查看模式

**✏️ 编辑器模式（默认）**
- 直接显示 JSON 格式的配置内容，可以编辑
- 有行号、彩色高亮

**🌳 树形浏览模式**
- 点击「树形预览」切换
- 配置以文件夹树的形式展示，可以展开/折叠每一层
- 适合不想看大段代码的人

## 6. 修改终端配置

### 修改单台配置

1. 进入终端详情页（如上一步）
2. 找到你要改的配置项，点击展开
3. 在编辑器里直接修改内容

**举个例子：** 想把某台终端的语言改成英文

```
找到 terminalFunction 面板
在 JSON 中找到 "language": "zh-CN"
改成 "language": "en-US"
```

4. 点击 **「保存」** 按钮（或按键盘快捷键 `Ctrl+S`）
5. 会弹出一个预览窗口，显示**修改前 → 修改后**的差异

```
┌──────────────────────────────────────────────┐
│  确认保存                                    │
│                                              │
│  修改项: terminalFunction/language           │
│                                              │
│  旧值: "zh-CN"                               │
│  新值: "en-US"                    ← 绿色高亮 │
│                                              │
│  [取消]  [确认保存]                           │
└──────────────────────────────────────────────┘
```

6. 确认无误后，点击 **「确认保存」**
7. 看到绿色提示「✅ 保存成功」就完成了

> ⚠️ **注意**：有些配置修改后需要重启终端应用才能生效。

### 如果终端离线了

如果终端不在线（状态显示 ❌），页面顶部会有一条橙色提示：

```
⚠️ 终端离线 — 无法读取或修改配置
[🔁 重试连接]
```

点击 **「重试连接」** 按钮，如果终端恢复正常，页面会自动刷新。

## 7. 批量操作（一次性改多台）

假设你有 20 台终端都要改同一个设置，不需要一个一个改。

### 操作步骤

**第一步：进入批量操作页**
- 点击顶部导航的 **「批量操作」**

**第二步：选择要改的终端**

有两种选法：

```
方法一：按分组选（推荐）
  ┌───────────────────────────────────────────┐
  │  点击分组标签「管理服务器」→ 自动勾选该    │
  │  组内的所有终端                            │
  │                                            │
  │  [管理服务器] ✓3/5   [默认分组] ✓0/3      │
  └───────────────────────────────────────────┘

方法二：单个勾选
  ☑ bhs-4 (100.66.5.26)
  ☐ kiosk-02 (100.66.5.27)
  ☑ kiosk-03 (100.66.5.28)
```

**第三步：填写配置内容**

```
要修改的配置项: [terminalFunction  ▼]  ← 下拉选择
配置新值:
┌──────────────────────────────────────────┐
│ {                                        │
│   "language": "en-US",                   │
│   "timeout": 60                          │
│ }                                        │
└──────────────────────────────────────────┘
[📋 格式化 JSON]  [👁️ 预览变更]
```

**第四步：执行推送**

1. 点击 **「推送到选中终端」**
2. 再次确认弹窗
3. 点击 **「确认推送」**
4. 等待进度条走完

**第五步：看结果**

```
✅ 成功: 18 台
❌ 失败: 2 台
  - kiosk-02 (100.66.5.27): 终端离线
  - kiosk-09 (100.66.5.34): 连接超时
```

失败的那几台可以后面再单独处理。

## 8. 配置对比（比较两台终端的不同）

想知道两台终端的配置是不是一样？哪里不一样？

1. 点击顶部导航的 **「配置对比」**
2. 勾选你要对比的终端（至少选 2 台）

```
☐ bhs-4 (100.66.5.26)
☑ kiosk-02 (100.66.5.27)
☑ kiosk-03 (100.66.5.28)
```

3. 选择要对比的配置项（按住 `Ctrl` 键可以选多个）
4. 点击 **「开始对比」**

结果表格：

```
┌────────────────────┬──────────────────┬──────────────────┐
│ 字段路径            │ kiosk-02         │ kiosk-03         │
├────────────────────┼──────────────────┼──────────────────┤
│ language           │ zh-CN            │ en-US      ← ≠   │
│ timeout            │ 30               │ 30               │
│ serverUrl          │ http://svr-a     │ http://svr-b ← ≠ │
│ enableFeature      │ true             │ true             │
├────────────────────┼──────────────────┼──────────────────┤
│                    │ 差异项: 2/4                            │
└────────────────────┴──────────────────┴──────────────────┘
```

- 橙色背景的行表示**有差异**（标注了 `≠`）
- 灰色背景的行表示**一样**

可以点击 **「导出 CSV」** 或 **「导出 Markdown」** 把结果保存下来。

## 9. 历史回滚（后悔了要恢复）

如果你改错了配置，想回到之前的版本：

**第一步：进入历史页面**

在终端详情页中，点击配置项面板右上角的 **📋 图标**

**第二步：查看修改记录**

```
┌─────────────────────────────────────────────────────────────┐
│  配置修改历史 — bhs-4 — terminalFunction                     │
│                                                             │
│  ┌──────────────┬──────────────────┬────────────────────┐   │
│  │ 修改时间      │ 旧值              │ 新值               │   │
│  ├──────────────┼──────────────────┼────────────────────┤   │
│  │ 2026-06-25   │ "zh-CN"          │ "en-US"            │   │
│  │ 10:30:22     │                  │                     │   │
│  ├──────────────┼──────────────────┼────────────────────┤   │
│  │ 2026-06-24   │ "ja-JP"          │ "zh-CN"      [回滚] │   │
│  │ 15:12:08     │                  │                     │   │
│  └──────────────┴──────────────────┴────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

**第三步：回滚**

- 找到你想恢复到的那个版本
- 点击右侧的 **「回滚到此版本」**
- 系统会自动把那一版的值写回终端
- 回滚操作本身也会记录在历史中

## 10. 常见问题

### Q1: 打开页面是白屏 / 显示不了 / 按钮没反应

按 `F12` 打开开发者工具 → 点 Console（控制台）标签 → 截图发给管理员。

最常见原因：
- 没有通过 `http://127.0.0.1:8300` 访问，而是双击 HTML 文件用 `file://` 打开
- 解决了之前的 `missing )` 语法错误问题，但如果你用的是旧版缓存，`Ctrl+Shift+R` 强制刷新

### Q2: 终端显示离线怎么办？

1. 先确认这台终端**有没有通电开机**
2. 确认终端上的 `config-serv` 服务有没有运行（在终端上执行 `curl http://localhost:8081/`）
3. 在详情页点击 **「重试连接」**
4. 如果还不行，联系网络管理员确认网络是通的

### Q3: 保存配置提示失败？

- 检查终端的在线状态（❌ 离线不能写配置）
- 检查 JSON 格式是否正确（少了逗号、多了括号都会报错）
- 点 **「格式化」** 按钮可以自动整理格式

### Q4: 改了配置但终端没生效？

- 成功提示「✅ 保存成功」只代表写入成功
- 某些配置项需要**重启终端应用**才能生效（具体看 config-serv 的文档）

### Q5: 如何加一台新终端到列表？

1. 在首页点击 **「➕ 添加终端」**
2. 填写：
   - **IP 地址**（必填）：终端在网络中的地址
   - **端口**（选填）：默认 8081
   - **别名**（选填）：一个好记的名字
   - **分组**（选填）：比如「大堂」「自助区」
3. 点击「添加」
4. 系统会自动检测终端是否在线，在线则添加成功

### Q6: 怎么卸载？

- **EXE 版**：直接删除 `KioskConfigCenter.exe` 即可（绿色软件，不写注册表）
- **服务版**：管理员身份运行 `.\scripts\install-service.ps1 -Action uninstall` 再删除文件夹

### Q7: 配置文件在哪？

- `terminals.yaml` — 终端列表（存着所有终端的 IP、别名、分组）
- `app/history/` — 配置修改历史记录（按终端 IP 分文件夹）

---

> **还是搞不定？** 把浏览器地址栏的网址、页面截图、控制台报错（F12 → Console）发给开发人员。

## 1. 测试环境要求

### 1.1 硬件与网络

| 资源 | 规格 | 数量 | 用途 |
|------|------|------|------|
| 管理服务器 | Python 3.11+, 可运行 Config Center | ≥ 1 台 | 部署被测系统 |
| 测试终端 A | 运行 config-serv 服务（在线） | ≥ 1 台 | 功能验证、读写测试 |
| 测试终端 B | 运行 config-serv 服务（在线） | ≥ 1 台 | 批量操作、对比测试 |
| 测试终端 C | 可停止 config-serv（模拟离线） | ≥ 1 台 | 离线场景测试 |
| 测试机 | 装有 Chrome/Edge 的 Windows 机器 | ≥ 1 台 | 浏览器访问测试 |

### 1.2 软件环境

| 软件 | 版本要求 |
|------|---------|
| Python | ≥ 3.11 |
| FastAPI | ≥ 0.100.0 |
| uvicorn | ≥ 0.20.0 |
| httpx | ≥ 0.24.0 |
| PyYAML | ≥ 6.0 |
| Jinja2 | ≥ 3.1 |
| 浏览器 | Chrome ≥ 110 / Edge ≥ 110 |

### 1.3 启动被测系统

```bash
# 方式一：Python 开发模式
cd d:\projects\kiosk-config-center
python run.py
# 访问 http://127.0.0.1:8300

# 方式二：EXE 模式
# 双击 dist/KioskConfigCenter.exe
```

### 1.4 终端配置准备

测试前确保 `terminals.yaml` 中包含至少 3 台终端配置，且至少有 2 台在线。

### B. 测试数据准备脚本

```python
"""快速准备测试数据的辅助脚本"""
import httpx
import asyncio

BASE = "http://127.0.0.1:8300"

async def setup_test_data():
    """向在线终端写入测试数据用于对比测试"""
    async with httpx.AsyncClient() as client:
        # 获取所有终端
        r = await client.get(f"{BASE}/api/terminals")
        terminals = r.json()
        online = [t for t in terminals if t["online"]]
        
        if len(online) < 2:
            print("需要至少 2 台在线终端")
            return
        
        # 写入不同的配置值
        await client.put(
            f"{BASE}/api/proxy/{online[0]['ip']}/config/terminalFunction",
            json={"demoMode": True, "configVersion": "v1.0.0"}
        )
        await client.put(
            f"{BASE}/api/proxy/{online[1]['ip']}/config/terminalFunction",
            json={"demoMode": False, "configVersion": "v2.0.0"}
        )
        print(f"测试数据已写入 {online[0]['ip']} 和 {online[1]['ip']}")

if __name__ == "__main__":
    asyncio.run(setup_test_data())
```
